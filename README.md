# Engenharia da Computação 💻⚙️

Aqui eu guardo os códigos, exercícios e projetos que vou fazendo ao longo da minha graduação em **Engenharia da Computação**. Uso esse espaço como um caderno de estudos para acompanhar minha evolução.

## 📂 O que tem por aqui

Organizei as pastas por matérias e temas que estou estudando:

* `01-algoritmos-e-programacao/` - Listas de exercícios, lógica e os primeiros códigos em C e Python.
* `02-estruturas-de-dados/` - Práticas com listas, pilhas, filas, árvores e ordenação.
* `03-arquitetura-de-computadores/` - Códigos em Assembly, circuitos lógicos e testes de hardware.
* `04-programacao-orientada-a-objetos/` - Trabalhos e exercícios usando Java e C++.

## 🛠️ Ferramentas que uso

* **Linguagens:** C, C++, Python, Java
* **Hardware e Simulação:** Arduino, Tinkercad, Logisim *(ajuste conforme suas aulas)*
* **Versionamento:** Git e GitHub
